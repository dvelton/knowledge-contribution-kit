# Security

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature. Do not place workplace
content, private links, credentials, or exploit details in a public issue.

## Data handling

The prompt-builder page is static and makes no network requests. Form entries
remain in the browser tab.

The generated prompt is intended for an AI assistant selected by the
contributor. If that assistant is hosted, information is processed under the
terms and settings that apply to that service. Confirm that the organization
approves it for the proposed information.

The project provides no connectors, accounts, analytics, telemetry, or hosted
data store.

## Source content

The generated prompt treats target material and workplace content as untrusted
data. It prohibits following instructions embedded in those sources,
transmitting source material, sending messages, or modifying the target.
